# Cairn GPU box image — the per-node serving env (sglang block-forward + the sealed wire). Proven on a
# real L4. The install is TWO steps — the second CANNOT be a requirements pin (see below):
#
#   pip install -r infra/requirements-gpu.txt
#   pip install --no-deps compressed-tensors==0.9.4        # REQUIRED override — see the note at the bottom
#
# Box prerequisites for flashinfer's RUNTIME JIT (not pip): the CUDA toolkit (nvcc, /usr/local/cuda) +
# ninja on PATH. The exact verified version set is infra/requirements.lock (a freeze of this env).
#
# Pin philosophy (learned the hard way — see git history): hard-pin ONLY what sglang does NOT control.
# sglang[srt] owns a deep, tightly-coupled stack (transformers, huggingface-hub, compressed-tensors,
# numpy, the CUDA kernels); an independent hard pin that disagrees with its resolution is
# ResolutionImpossible — the old transformers==4.45.2 / huggingface-hub==0.25.2 / compressed-tensors==0.9.4
# pins EACH broke the install this way. So let sglang resolve them; pin only the wire + config deps.

# per-node serving engine — we wrap it at block granularity, don't rebuild it.
sglang[srt]==0.4.6.post5  # [srt] = the inference-runtime extra (REQUIRED): pulls runtime-common
                          # (transformers==4.51.1 + pydantic + huggingface-hub) + the CUDA kernels
                          # sgl-kernel==0.1.4 + flashinfer-python==0.2.5. Bare `sglang` is only the
                          # client shell (imports, can't serve). g7e/Blackwell (sm_100): the `blackwell` extra.
torch==2.6.0              # sglang 0.4.6.post5 requires it; the default PyPI wheel is +cu124 (matches the L4 driver).

# the sealed wire (fork/shard/wire.py) — NOT a sglang dep, so pin it here (sglang won't pull it).
cryptography==43.0.1
# config loading (cairn_scheduler.load_model_config) — harmless, widely compatible.
pyyaml==6.0.2
